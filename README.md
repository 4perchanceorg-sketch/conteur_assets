# conteur_assets

Fichiers statiques hébergés pour le générateur Perchance "Conteur+CYOA" (contourne la limite de taille de sauvegarde de Perchance : les gros blocs statiques — i18n, templates HTML des panneaux — sont extraits ici et chargés à l'exécution via `fetch()`).

Aucune donnée sensible : le contenu est de toute façon injecté tel quel dans la page et visible côté client.
